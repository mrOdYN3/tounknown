Buttons for all actions. The primary variant is named "gold" (source class `btn-gold`) but renders an ink-black pill with white text — the Apple move; gold stays reserved for meaning.

```jsx
<Button>Begin a Path</Button>
<Button variant="ghost">Sit 15 min free</Button>
<Button variant="quiet">not now</Button>
<Button wide>Give with a free heart</Button>
```

Press-scale 0.97 with spring easing. Copy is sentence case, calm, never salesy.
