# UI Kit — toUnknown Admin Studio

Recreation of `tounknown-admin.html` — the dark desktop CMS DYN uses to edit the app's content (brand copy, paths, payments) and export the `tu-config` JSON. Sidebar navigation + form views on night surfaces, same gold accent and spring motion as the app.

- `index.html` — entry; sidebar + Brand / Paths / Payments views (interactive tab switching).

Deliberately compact: form patterns (inputs, selects, labels, cards, buttons) are shown on the Brand view; Paths and Payments show list/row patterns. Export flow is visual only.
